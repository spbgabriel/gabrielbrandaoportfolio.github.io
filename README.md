# 🌐 Personal Portfolio - Gabriel Brandão

This is the repository for my personal portfolio website. It serves as a central hub to showcase my skills, certifications, and the projects I've built as a Front-End Engineer.

**Live Link:** [gabrielbrandaoportfolio.vercel.app](https://gabrielbrandaoportfolio.vercel.app/)

---

## 🚀 Overview

The goal of this project was to create a clean, professional, and responsive digital resume that highlights my journey in web development. It is designed to be lightweight, fast, and easy to navigate for recruiters and fellow developers.

### Key Features:
- **Responsive Design:** Optimized for mobile, tablet, and desktop views.
- **Project Gallery:** Showcase of my top projects with direct links to GitHub.
- **Certifications:** Verified links to my achievements from Codecademy and Alura.
- **Contact Integration:** Easy access to my LinkedIn, GitHub, and email.

---

## 🛠️ Built With

This project was built using core web technologies to ensure a strong foundation in Front-End fundamentals:

* **HTML5** - Semantic structure for accessibility and SEO.
* **CSS3** - Custom styling with a focus on modern layouts (Flexbox/Grid).
* **JavaScript** - Interactive elements and dynamic content.
* **Vercel** - Hosting and Continuous Deployment.
